Internal Tool / Prototype

Construction Inspection

A workflow web app for site inspection records, photo tracking, and issue management across construction and spatial design QA processes.

Role

Product Designer (UI/UX) & Builder

Focus

Cross-disciplinary UX / Digital Transformation / Web Automation

The Challenge

Inspection records were historically difficult to track, with photos, defect logs, and progress updates entirely disconnected. The heavy field use required in physical architecture and interior design site surveys demands a digital tool that seamlessly bridges on-site realities with back-office project management.

Key Features

Real-Time Status Tracking

Clear visual status tags and live syncing ensure both field teams and project stakeholders view up-to-the-minute acceptance data.

On-Site Photo Capture

Integrated tools to mark up defect areas directly on photos with structured details, built for high visibility on active sites.

Instant PDF Export

Automated backend workflows instantly format raw inspection data and images into structured, client-ready PDF reports.

Project Gallery

Process

1. Study the Workflow

Started from the true sequence of physical site inspection work and cross-functional team needs, rather than leading with interface styling.

2. Clarify Records and States

Defined exactly what data needed to be captured on mobile devices, reviewed by management, and followed up on.

3. Build the Tool Logic

Created a scalable digital structure for status tracking, defect visibility, and seamless documentation flow.

4. Prototype the Product

Developed high-fidelity prototypes to demonstrate systems thinking, testing edge cases, and proving actual making capability.

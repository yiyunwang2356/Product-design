Operational System

Nomadd Haus

A hybrid space operation system connecting bookings, space usage, and community touchpoints into a clearer service ecosystem.

Role

System Designer / Operator

Focus

Business System Design / Community / Service Ecosystem

Challenge

Space management, booking, and community interactions were handled through disconnected tools and workflows.

Project gallery

Process

1. Define the operational landscape

Clarified the different roles, spaces, and service touchpoints involved in daily operations.

2. Connect the ecosystem

Mapped how booking, communication, and management should support each other.

3. Create a system structure

Built a clearer interface and content logic for operations and community activity.

4. Present the service logic

Turned the complexity into a portfolio narrative that feels organized and product-led.
